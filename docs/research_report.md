# Research Report — Fraud & Anomaly Detection

**Supervised vs unsupervised fraud detection under extreme imbalance: an evaluation discipline centered on precision, review capacity and cost**

*Author: Aydin Monavvari — educational research project (not a production fraud system).*
*Run date: 2026-10-08 (rerun after methodology fix). Committed results use the repository's clearly-labeled synthetic generator; no real-dataset numbers are claimed.*

---

## Abstract

Fraud detection combines extreme class imbalance (~0.17% positives in the canonical dataset), asymmetric error costs, and capacity-constrained review operations — three properties under which the usual "train, then report ROC-AUC" workflow produces misleading conclusions. This study contrasts Isolation Forest (unsupervised, label-free) with three supervised classifiers (logistic regression, random forest, gradient boosting with class weights) on a seeded, clearly-labeled synthetic dataset engineered to the statistical shape of PCA-anonymized card-fraud data, including 15% "stealth" fraud drawn i.i.d. from the legitimate distribution — those rows carry no marginal signal in any single feature, capping univariate detectability by design (a design cap, not a proof of Bayes-optimality). Evaluation is PR-AUC-first, complemented by precision@0.1%/1% (review-queue operating points) and a cost-optimal threshold under a 10:1 FN:FP cost model selected on a dedicated validation split; the test set is scored exactly once, at that fixed threshold. In the committed run, ROC-AUC spans only 0.87–0.94 across models while PR-AUC spans 0.095–0.614: random forest leads (PR-AUC 0.614; precision@1% = 0.139, an ≈81× lift over the 0.0017 base rate), gradient boosting and logistic regression trail (0.316/0.262), and Isolation Forest quantifies the unsupervised handicap (0.095). Validation-selected thresholds range from 0.0001 to 0.94 across models, demonstrating that operating points — not models alone — determine deployed behavior. All committed numbers are properties of the labeled generator; the acquisition path for the real (Kaggle-gated) dataset is documented for honest user-side reproduction.

## Introduction

Fraud analytics differs from most classification problems in three structural ways. First, positives are vanishingly rare, so metrics built on the abundant negative class (ROC, accuracy) lose discriminative meaning. Second, errors are asymmetric and economic: a missed fraud and a blocked legitimate customer have different, institution-specific costs. Third, response capacity is bounded: models are consumed as ranked queues ("investigate the top k%"), not as absolute verdicts. This study builds the evaluation layer that matches those realities and applies it to an unsupervised/supervised model comparison, using a reproducible synthetic stand-in for the gated real dataset — with the stand-in labeled in every artifact.

## Research Question

> Under extreme class imbalance, how do unsupervised and supervised fraud-detection approaches compare on precision-centered, capacity-aware, cost-aware evaluation — and how much of the performance difference is model vs operating point?

## Data

| Property | Synthetic mode (committed) | Kaggle mode (documented, user-run) |
| --- | --- | --- |
| Provenance | generated by this repository, seed 42 | ULB creditcard.csv (user-downloaded) |
| Shape | 60,000 × (28 components + Amount + Class) | 284,807 × (28 PCA + Amount + Class) |
| Fraud rate | ~0.17% | 0.173% |
| Stealth fraud | 15% (i.i.d. from the legitimate distribution; no univariate signal by design) | unknown |
| Split | stratified 49/21/30 train/validation/test, seed 42 | same |

The generator draws legitimate rows from a standard Gaussian across 28 components; detected (non-stealth) frauds receive a moderate location shift (≈1.7σ) on three deterministic plus four seeded-random components, a widened first component, and a heavier-tailed amount distribution; the 15% "stealth" fraud rows are overwritten last with fresh i.i.d. draws from the legitimate distributions for every feature column AND the amount, so they carry no marginal signal in any single feature. This caps univariate detectability by design and keeps achievable PR-AUC strictly below 1 (a design cap, not a proof of Bayes-optimality). Every artifact marks this provenance.

## Methodology

**Arms.** (1) Isolation Forest: 300 trees, `contamination` set to the fraud rate, trained on unlabeled training features; anomaly score = negative `score_samples`. (2) Supervised: logistic regression, random forest, gradient boosting, all `class_weight`-balanced, all preprocessing inside pipelines, all seeds pinned.

**Splits and threshold selection.** A stratified three-way split (train 49% / validation 21% / test 30%, seed 42) separates model fitting from every model-free decision. Models fit on the training split only; the cost-optimal threshold is computed on the validation split's scores and labels; the test split is used exactly once, for the reported discrimination, precision@k and cost/confusion metrics at that fixed threshold. The committed JSON and CSV record `threshold_source: validation` for every model, and a unit-test guard asserts the selection routine is invoked with validation labels and never with test labels.

**Metrics.** PR-AUC with base-rate context; ROC-AUC reported with an explicit misuse caveat; precision/recall at the top 0.1% and 1% of the score distribution (test split); expected cost `10·FN + 1·FP`; the threshold on the validation precision–recall curve minimizing that cost, with the test-set confusion matrix at that point.

**Integrity design.** Two data modes with mandatory provenance labeling; unit tests pin the generator's fraud rate, shape and signal structure, verify that the stealth subset is statistically indistinguishable from legitimate rows on every column (per-feature standardized mean differences and Kolmogorov–Smirnov tests) and that univariate detectability is capped at chance (AUC ≈ 0.5 for V1 and Amount), assert that the cost-optimal threshold is selected on validation labels only (and that the recorded threshold equals the validation-computed one), and verify the Kaggle mode fails loudly when the user has not supplied data; the repository never redistributes the real dataset and commits no real-data numbers.

## Experimental Design

The design isolates three comparisons: (i) unsupervised vs supervised (with identical features and splits), (ii) models within the supervised arm, and (iii) operating points within each model (threshold sweep under the cost model). Because the synthetic generator is deterministic, every comparison is exactly reproducible; because the real dataset cannot be committed, the study's claims are scoped to the generator — an explicit trade of external validity for reproducibility, documented rather than hidden.

## Results

Actual outputs of the committed synthetic-mode run (`reports/fraud_results.json`):

| Model | PR-AUC ↑ | ROC-AUC | Precision@1% | Recall@1% | Cost-opt. threshold (val) | Expected cost |
| --- | --- | --- | --- | --- | --- | --- |
| Random forest | **0.614** | 0.937 | 0.139 | 0.806 | 0.129 | **154** |
| Gradient boosting | 0.316 | 0.902 | 0.111 | 0.645 | 0.0001 | 190 |
| Logistic regression | 0.262 | 0.903 | 0.122 | 0.710 | 0.936 | 169 |
| Isolation Forest | 0.095 | 0.875 | 0.056 | 0.323 | 0.512 | 281 |

Split: train 29,400 (50 frauds) · validation 12,600 (21 frauds) · test 18,000 (31 frauds). Thresholds are selected on the validation split only (`threshold_source: validation` in the JSON); the test set is scored once at that fixed threshold. Base rate: 0.0017. At the validation-selected operating point, random forest catches 17 of 31 test frauds while flagging 14 legitimate transactions.

## Discussion

1. **ROC-AUC compresses a 6.5× performance range into a 7-point band.** All models score 0.87–0.94 ROC-AUC because the negative class is enormous; PR-AUC separates them 0.095 → 0.614. This is the clearest possible demonstration of why PR analysis is mandatory under imbalance.
2. **Unsupervised detection pays a quantified tax.** Isolation Forest reaches 0.095 PR-AUC without labels — useful when labels are absent, but its expected cost (281) is 1.8× the best supervised model's (154). The gap is the price of label-freedom, not an implementation flaw.
3. **Within supervised learning, nonlinearity is the differentiator.** Random forest more than doubles logistic regression's PR-AUC (0.614 vs 0.262) at nearly identical ROC-AUC — the ranking quality that matters (top-of-queue precision) lives in the interaction structure.
4. **Operating points are model-specific and extreme.** Validation-selected thresholds span 0.0001–0.94. A universal "0.5" would be arbitrary for several models: scoring the test set at 0.5 instead of the validation-selected threshold would multiply expected cost by 2.0× for random forest (310 → 154) and 7.8× for logistic regression (1,315 → 169).
5. **Evidence discipline.** The committed numbers are honest about being synthetic; the 15% stealth fraction is drawn i.i.d. from the legitimate distribution, which caps univariate detectability and keeps achievable PR-AUC below 1 by design, preventing the over-optimistic "perfect detection" pattern that naive generators produce — a design cap, not a proof of Bayes-optimality. Threshold selection is confined to the validation split, and the test set is touched once.

## Limitations

- **Synthetic evidence.** Real fraud is adversarial and non-stationary; the generator models neither. All absolute numbers are generator-relative.
- **Static, single split.** No temporal validation, drift, or adversarial adaptation.
- **Threshold selection on a small validation split.** The dedicated validation split contains only 21 frauds (test: 31), so the validation-selected threshold — and the test-set cost and confusion estimates at that threshold — carry substantial sampling uncertainty; cross-model cost comparisons are indicative, not precise.
- **Illustrative cost ratio.** The 10:1 FN:FP ratio varies substantially across institutions and fraud types.
- **No resampling arms.** SMOTE/undersampling comparisons are deliberately deferred; class weights plus thresholds avoid distorting the evaluation distribution.
- **No sequence/graph features.** Card-fraud production systems use temporal and network structure absent here.

## Conclusion

Under extreme imbalance, the evaluation layer — PR-centered metrics, capacity operating points, and cost-based thresholds — changes conclusions that ROC-based comparison cannot even rank. In the committed labeled-synthetic study, supervised models dominate the unsupervised detector, nonlinearity dominates within the supervised arm, and operating points contribute as much to deployed cost as model choice. The repository demonstrates an integrity pattern for gated data: labeled synthetic reproduction, documented acquisition, and zero fabricated real-world claims.
