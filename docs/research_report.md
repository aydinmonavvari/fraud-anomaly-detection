# Research Report — Fraud & Anomaly Detection

**Supervised vs unsupervised fraud detection under extreme imbalance: an evaluation discipline centered on precision, review capacity and cost**

*Author: Aydin Monavvari — educational research project (not a production fraud system).*
*Run date: 2026-10-08. Committed results use the repository's clearly-labeled synthetic generator; no real-dataset numbers are claimed.*

---

## Abstract

Fraud detection combines extreme class imbalance (~0.17% positives in the canonical dataset), asymmetric error costs, and capacity-constrained review operations — three properties under which the usual "train, then report ROC-AUC" workflow produces misleading conclusions. This study contrasts Isolation Forest (unsupervised, label-free) with three supervised classifiers (logistic regression, random forest, gradient boosting with class weights) on a seeded, clearly-labeled synthetic dataset engineered to the statistical shape of PCA-anonymized card-fraud data, including 15% "stealth" fraud that is undetectable by construction. Evaluation is PR-AUC-first, complemented by precision@0.1%/1% (review-queue operating points) and a cost-optimal threshold under a 10:1 FN:FP cost model. In the committed run, ROC-AUC spans only 0.91–0.98 across models while PR-AUC spans 0.13–0.73: random forest leads (PR-AUC 0.728; precision@1% = 0.150, an 88× lift over the 0.0017 base rate), logistic regression and gradient boosting trail (0.31/0.42), and Isolation Forest quantifies the unsupervised handicap (0.130). Thresholds minimizing expected cost range from 0.0002 to 0.99 across models, demonstrating that operating points — not models alone — determine deployed behavior. All committed numbers are properties of the labeled generator; the acquisition path for the real (Kaggle-gated) dataset is documented for honest user-side reproduction.

## Introduction

Fraud analytics differs from most classification problems in three structural ways. First, positives are vanishingly rare, so metrics built on the abundant negative class (ROC, accuracy) lose discriminative meaning. Second, errors are asymmetric and economic: a missed fraud and a blocked legitimate customer have different, institution-specific costs. Third, response capacity is bounded: models are consumed as ranked queues ("investigate the top k%"), not as absolute verdicts. This study builds the evaluation layer that matches those realities and applies it to an unsupervised/supervised model comparison, using a reproducible synthetic stand-in for the gated real dataset — with the stand-in labeled in every artifact.

## Research Question

> Under extreme class imbalance, how do unsupervised and supervised fraud-detection approaches compare on precision-centered, capacity-aware, cost-aware evaluation — and how much of the performance difference is model vs operating point?

## Data

| Property | Synthetic mode (committed) | Kaggle mode (documented, user-run) |
| --- | --- | --- |
| Provenance | generated by this repository, seed 42 | ULB creditcard.csv (user-downloaded) |
| Shape | 60,000 × (28 components + Amount + Class) | 284,807 × (28 PCA + Amount + Class) |
| Fraud rate | ~0.17% | 0.173% |
| Stealth fraud | 15% (undetectable by construction) | unknown |
| Split | stratified 70/30, seed 42 | same |

The generator draws legitimate rows from a standard Gaussian across 28 components; detected frauds receive a moderate location shift (≈1.7σ) on three deterministic plus four seeded-random components, a widened first component, and a heavier-tailed amount distribution; 15% of frauds are "stealth" (identical to legitimate) so the Bayes-optimal PR-AUC is strictly below 1. Every artifact marks this provenance.

## Methodology

**Arms.** (1) Isolation Forest: 300 trees, `contamination` set to the fraud rate, trained on unlabeled training features; anomaly score = negative `score_samples`. (2) Supervised: logistic regression, random forest, gradient boosting, all `class_weight`-balanced, all preprocessing inside pipelines, all seeds pinned.

**Metrics.** PR-AUC with base-rate context; ROC-AUC reported with an explicit misuse caveat; precision/recall at the top 0.1% and 1% of the score distribution; expected cost `10·FN + 1·FP`; the threshold on the precision–recall curve minimizing that cost, with the confusion matrix at that point.

**Integrity design.** Two data modes with mandatory provenance labeling; unit tests pin the generator's fraud rate, shape and signal structure, and verify the Kaggle mode fails loudly when the user has not supplied data; the repository never redistributes the real dataset and commits no real-data numbers.

## Experimental Design

The design isolates three comparisons: (i) unsupervised vs supervised (with identical features and splits), (ii) models within the supervised arm, and (iii) operating points within each model (threshold sweep under the cost model). Because the synthetic generator is deterministic, every comparison is exactly reproducible; because the real dataset cannot be committed, the study's claims are scoped to the generator — an explicit trade of external validity for reproducibility, documented rather than hidden.

## Results

Actual outputs of the committed synthetic-mode run (`reports/fraud_results.json`):

| Model | PR-AUC ↑ | ROC-AUC | Precision@1% | Recall@1% | Cost-opt. threshold | Expected cost |
| --- | --- | --- | --- | --- | --- | --- |
| Random forest | **0.728** | 0.983 | 0.150 | 0.871 | 0.183 | **99** |
| Gradient boosting | 0.416 | 0.943 | 0.139 | 0.807 | 0.0002 | 158 |
| Logistic regression | 0.308 | 0.979 | 0.139 | 0.807 | 0.993 | 154 |
| Isolation Forest | 0.130 | 0.914 | 0.061 | 0.355 | 0.517 | 258 |

Base rate: 0.0017. At the cost-optimal operating point, random forest catches 22 of 31 test frauds while flagging 9 legitimate transactions.

## Discussion

1. **ROC-AUC compresses a 5.6× performance range into a 7-point band.** All models score 0.91–0.98 ROC-AUC because the negative class is enormous; PR-AUC separates them 0.13 → 0.73. This is the clearest possible demonstration of why PR analysis is mandatory under imbalance.
2. **Unsupervised detection pays a quantified tax.** Isolation Forest reaches 0.130 PR-AUC without labels — useful when labels are absent, but its expected cost (258) is 2.6× the best supervised model's. The gap is the price of label-freedom, not an implementation flaw.
3. **Within supervised learning, nonlinearity is the differentiator.** Random forest more than doubles logistic regression's PR-AUC at nearly identical ROC-AUC — the ranking quality that matters (top-of-queue precision) lives in the interaction structure.
4. **Operating points are model-specific and extreme.** Cost-optimal thresholds span 0.0002–0.99. A universal "0.5" would be arbitrary for every model; threshold selection moved expected cost by 2.6× for Isolation Forest alone.
5. **Evidence discipline.** The committed numbers are honest about being synthetic; the 15% stealth fraction caps achievable PR-AUC below 1 by construction, preventing the over-optimistic "perfect detection" pattern that naive generators produce.

## Limitations

- **Synthetic evidence.** Real fraud is adversarial and non-stationary; the generator models neither. All absolute numbers are generator-relative.
- **Static, single split.** No temporal validation, drift, or adversarial adaptation.
- **Illustrative cost ratio.** The 10:1 FN:FP ratio varies substantially across institutions and fraud types.
- **No resampling arms.** SMOTE/undersampling comparisons are deliberately deferred; class weights plus thresholds avoid distorting the evaluation distribution.
- **No sequence/graph features.** Card-fraud production systems use temporal and network structure absent here.

## Conclusion

Under extreme imbalance, the evaluation layer — PR-centered metrics, capacity operating points, and cost-based thresholds — changes conclusions that ROC-based comparison cannot even rank. In the committed labeled-synthetic study, supervised models dominate the unsupervised detector, nonlinearity dominates within the supervised arm, and operating points contribute as much to deployed cost as model choice. The repository demonstrates an integrity pattern for gated data: labeled synthetic reproduction, documented acquisition, and zero fabricated real-world claims.
